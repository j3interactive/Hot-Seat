# Mockup

An interactive mockup ("Hot Seating Chart Mockup") was built on 2026-10-28 as a private Claude design canvas owned by Jason Reed. It shows:

- the Main Floor laid out like the Floor tab of the Metro chart, plus Escalations, Nesting and The Academy tabs;
- day tabs (Mon–Sat) with sample open seats taken from the spreadsheet;
- click-to-claim and release, supervisor filter, "open seats only" highlight;
- seat notes (D8 keyboard rule) and an area block (Escalations closed Wednesday AM).

The coordinates in `data/floor-layout.json` match the mockup, so the production map can render from that file directly.

Sample availability in the mockup is illustrative only; it is not stored here.
